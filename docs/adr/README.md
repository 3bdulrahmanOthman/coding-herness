# Architecture Decision Records

ADRs capture decisions, context, consequences, and validation. Accepted decisions should not be silently reopened. A POC validates implementation feasibility; it does not automatically change the decision.

## Status vocabulary

- **Accepted:** approved project direction.
- **Proposed:** recommendation awaiting explicit approval.
- **Superseded:** replaced by a later ADR.
- **Deprecated:** no longer recommended.
